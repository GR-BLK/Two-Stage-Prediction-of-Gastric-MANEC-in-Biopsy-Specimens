# UNI2 Patch Feature Extraction

Extract patch-level features from WSI patches using the UNI2 vision transformer.

## ⚠️ Data & Model Notice

- This repository contains **no patient data** and **no model weights**.
- The UNI2 weights are **not** included. Download them from the original
  release and comply with their license and citation requirements.
- Users are responsible for ensuring that any data they process is handled
  in accordance with local ethics and privacy regulations.
