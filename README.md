# Two-Stage-Prediction-of-Gastric-MANEC-in-Biopsy-Specimens
WSI and clinical data pipeline: tile extraction, quality filtering, stain normalization, UNI2 patch feature extraction, and multimodal classification. Supports CLAM pooling, gated/contrastive fusion, LASSO clinical selection, 10-fold CV, external testing, BCa CIs, ROC/DCA, and Excel reports. Research use only.
